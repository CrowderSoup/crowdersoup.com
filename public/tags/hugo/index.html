Tina CMS

by Aaron Crowder on Friday, September 27, 2024 in Site Updates hugo

I’m trying out TinaCMS. I heard about it on Twitter, looked it up, and realized that it could add a configurable UI backend for my Hugo blog. This post is mainly for me to tinker with it and see if it’s something I’d enjoy using.

Features

  • Rich text editor (with the ability to toggle back to markdown)
  • Media manager (for adding images or other files)
  • Collections (posts or pages)

Collections are at the core of everything. They’re the blog posts, pages, etc. An item in a collection has fields which are configurable in your tina config.ts file.

I’ve been making some efforts to streamline the publishing process for this site. I’ve read about tools like Netlify and Lektor, but I wanted to keep things as close to a basic Hugo site as possible.
